# 🧾 Inventory & Stock Management System (Python)

## 📌 Project Overview

This project is a simple **Inventory & Stock Management System** developed in Python. It allows users to manage items, track stock levels, and perform operations like adding, updating, issuing, and deleting inventory items.

The project is designed to apply core programming concepts such as:

* Classes & Objects
* File Handling
* Lists & Data Processing
* Conditional Logic & Loops

As per the project guidelines, it demonstrates solving a real-world problem using structured programming and modular design.

---

## 🎯 Objective

The goal of this project is to:

* Manage inventory efficiently
* Track stock availability
* Provide insights like low stock alerts and top expensive items
* Store and retrieve data using files

---

## ⚙️ Features

### 🔹 Core Functional Modules

* Add new items to inventory
* View complete inventory report
* Update item stock
* Issue items (simulate sales)
* Delete items

### 🔹 Advanced Features

* Top 3 most expensive items
* Highest stock item detection
* Low stock report (alerts when quantity < 5)
* Automatic data persistence using file storage

---

## 🛠️ Technologies Used

* Python 3
* File Handling (`.txt` file storage)
* Object-Oriented Programming (OOP)

---

## 🧠 Code Structure

### Class:

* `Item` → Stores name, quantity, and price of items

### Functions:

* `show_inventory()` → Displays inventory and alerts low stock
* `save_inventory()` → Saves data to file
* `load_inventory()` → Loads data from file
* `menu()` → Main interface for user interaction

---

## ▶️ How to Run the Project

1. Install Python (if not already installed)
2. Save the file as:

   ```
   inventory_manager.py
   ```
3. Run the program:

   ```
   python inventory_manager.py
   ```
