#Inventory & Stock Management System

## Project Overview
A python based inventory management system that allows usres to add, view, update, issue (sell), and delete items.It also provides low stock alerts,calculates total inventory value, and saves data to  a text file for persistence.

## Features
-Add new items with name, quantity, and price
-View inventory with low stock alerts
-Update stock quantity
-Issue (Sell) items
-Delete items
-Calculate total inventory value
-Save and load inventory from'inventory.txt'
-Reports:
  -Top 3 most expensive items 
  -Highest stock item
  -Low stock report

## How to Run
1. Clone or download this project folder.
2. open the folder in VS Code.
3. Run the program:
'''bash
python inventory_manager.py
